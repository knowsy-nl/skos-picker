<skos-picker>

A framework-agnostic SKOS concept picker. This page contains no React, no JSX, and no build pipeline — only one <script type="module"> tag and the custom element. Drop the same two lines into any .html, .razor or server-rendered template and the picker behaves identically.

1 · Default — Cuisine picker, single value

Minimal markup. Three attributes: scheme-id, value, name. The element behaves like a form control: the chosen value is submitted as CuisineId.

(form not submitted yet)
<form>
  <skos-picker
    name="CuisineId"
    scheme-id="Cuisine"
    value="Italian"></skos-picker>
  <button type="submit">Save</button>
</form>
2 · Multi-select — Music Genre

Add the multiple attribute and the picker renders chips. Submitted as a comma-separated string. Try typing "rap" (an alternative name) or "bebop". 

<skos-picker
  name="MusicGenreIds"
  scheme-id="Music-Genre"
  multiple></skos-picker>
3 · Stripped-down — every visual extra turned off

Every cosmetic feature can be opted out of with a hide-* attribute. Useful when the dropdown should look exactly like the existing app. 

<skos-picker
  scheme-id="Programming-Language"
  value="Python"
  hide-footer
  hide-notations
  hide-alt-labels
  hide-definitions
  hide-counter
  hide-group-headers></skos-picker>
4 · Granular footer — keep hints, hide the scheme code

Hide just the bits the team doesn't want. Below: keyboard hints stay, the Programming-Language scheme code is gone. 

<skos-picker scheme-id="Programming-Language" hide-scheme-code></skos-picker>
5 · Theming — match the host page colours

The element exposes CSS custom properties so the host page can theme it without touching its internals. Below: a darker accent. 

<skos-picker
  scheme-id="Roast-Level"
  style="
    --skos-picker-border: #6f42c1;
    --skos-picker-active-bg: #f3e8ff;
    --skos-picker-chip-fg: #5b21b6;
  "></skos-picker>
6 · Listening for changes from plain JavaScript

The element fires a change event with event.detail.value. Works with jQuery, vanilla JS, knockout, anything.

change event will appear here…
const picker = document.getElementById('picker-6');
picker.addEventListener('change', (e) => {
  console.log('user picked', e.detail.value);
});
7 · Multilingual — one payload, switch language live

This picker loads from a data-source whose labels are language maps ({ "en": …, "nl": … }). The buttons just flip the lang attribute — labels switch instantly with no re-fetch, and the selected value (the concept IRI) is unchanged.

value (always the IRI) will appear here…
<skos-picker scheme-id="Cuisine" lang="en"
             data-source="…returns language maps…"></skos-picker>
// switch language — no re-fetch, value (IRI) stays put:
picker.setAttribute('lang', 'nl');
