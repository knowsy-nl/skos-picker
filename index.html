<skos-picker>

A framework-agnostic SKOS taxonomy picker. Two interchangeable implementations — pick the one that fits your stack.

Vanilla web component →

The <skos-picker> custom element. Drop a single <script> tag into any HTML / .cshtml / .razor page. No framework.

React component →

The <SkosPicker> React component, same UX, for a React app.

See README.md for usage, attributes and the production data-source contract.
